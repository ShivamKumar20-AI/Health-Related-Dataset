# Health-Related Dataset

A collection of health-related datasets used for exploratory data analysis, visualisation, and machine learning classification experiments.

## Datasets Included

### 1. Breast Cancer Dataset
- **Source:** UCI Machine Learning Repository (via scikit-learn)
- **Task:** Binary classification — malignant vs. benign
- **Features:** 30 numeric features derived from digitised images of fine needle aspirate (FNA) of breast mass
- **Records:** 569 samples

### 2. Diabetes Dataset
- **Source:** Pima Indians Diabetes Database
- **Task:** Binary classification — diabetic vs. non-diabetic
- **Features:** 8 health metrics (glucose, BMI, age, blood pressure, etc.)
- **Records:** 768 samples
